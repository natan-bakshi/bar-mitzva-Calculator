# מחשבון בר מצווה

מחשבון אינטרנטי לחישוב תאריך בר המצווה על פי תאריך הלידה הלועזי. המחשבון ממיר את תאריך הלידה לתאריך עברי, מוסיף 13 שנים עבריות ומציג את תאריך בר המצווה ואת פרשת השבוע בשבת הסמוכה, לפי מנהג ארץ ישראל.

## תכונות

- המרת תאריך לידה לועזי לתאריך עברי.
- תמיכה בלידה שהתרחשה לאחר השקיעה: במקרה כזה התאריך העברי מחושב מהיום העברי הבא.
- חישוב תאריך בר המצווה העברי והלועזי.
- הצגת פרשת השבוע בשבת של בר המצווה.
- טיפול במקרים מיוחדים בחודשי אדר, חשוון וכסלו כאשר היום ה־30 אינו קיים בשנה הרלוונטית.
- ממשק בעברית, בכיוון כתיבה מימין לשמאל, המותאם גם למסכים קטנים.

## שימוש

1. פותחים את `index.html` בדפדפן.
2. בוחרים את תאריך הלידה הלועזי.
3. מסמנים את האפשרות **הלידה התרחשה לאחר השקיעה** כאשר היא רלוונטית.
4. לוחצים על **חשב תאריך**.

תוצאות החישוב יוצגו מתחת לטופס.

## הפעלה מקומית

אין צורך בהתקנה או בשרת מקומי. אפשר לפתוח את הקובץ ישירות בדפדפן. לחלופין, ניתן להפעיל שרת סטטי מתוך תיקיית הפרויקט, לדוגמה:

```bash
python3 -m http.server 8000
```

לאחר מכן נכנסים לכתובת [http://localhost:8000](http://localhost:8000).

## טכנולוגיות

- HTML, CSS ו־JavaScript ללא שלב build.
- [Tailwind CSS](https://tailwindcss.com/) דרך CDN לעיצוב.
- [Hebcal](https://www.hebcal.com/) דרך CDN להמרת תאריכים עבריים ולחישוב פרשות השבוע.
- [Frank Ruhl Libre](https://fonts.google.com/specimen/Frank+Ruhl+Libre) דרך Google Fonts.

## דרישות

נדרש חיבור לאינטרנט בעת טעינת הדף, משום ש־Tailwind CSS, Hebcal והפונט נטענים ממקורות חיצוניים.
